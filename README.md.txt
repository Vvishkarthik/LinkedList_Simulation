# 🔗 Linked List Simulation in C

A menu-driven program that simulates **Singly Linked List operations** using dynamic memory allocation.

## 🧩 Features

- Insert at Beginning  
- Insert at End  
- Insert at a Given Position  
- Delete from Beginning  
- Delete from End  
- Search for an Element  
- Count Total Nodes  
- Display List as `data -> data -> NULL`

## 🧠 Data Structure

```c
struct node {
    int data;
    struct node *next;
};
